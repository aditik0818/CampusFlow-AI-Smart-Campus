# 🚀 CampusFlow – AI-Powered Smart Campus Assistant

CampusFlow is an AI-powered smart campus web application designed to make campus issue reporting, tracking, and management easier for students and administrators.

It provides a centralized platform where students can report everyday campus issues such as infrastructure problems, Wi-Fi failures, cleanliness issues, hostel problems, security concerns, and lost & found items.

AI helps analyze complaints, categorize them, determine priority, generate summaries, and recommend the appropriate department.

---

## 🎯 Problem Statement

College students often face difficulty in reporting and tracking everyday campus issues.

Problems such as:

- Broken classroom equipment
- Wi-Fi issues
- Water leakage
- Cleanliness problems
- Hostel and transport issues
- Security concerns
- Lost & found items

are often reported through scattered communication channels, making it difficult to track complaint status and follow up on unresolved issues.

CampusFlow provides a centralized and intelligent solution for managing these campus problems.

---

## 💡 Solution

CampusFlow connects students and administrators through one intelligent campus platform.

Students can:

- Report campus issues
- Upload images as evidence
- Get AI-based complaint analysis
- Track complaint status
- View announcements
- Explore campus issue locations
- Report lost and found items
- Interact with an AI campus assistant

Administrators can:

- View reported complaints
- Monitor priority issues
- Update complaint status
- Analyze issue trends
- Monitor campus hotspots
- Manage campus complaints efficiently

---

## ✨ Key Features

### 👩‍🎓 Student Dashboard

- Personalized student dashboard
- Complaint statistics
- Recent complaints
- Complaint status tracking
- Quick issue reporting
- Campus announcements

### 🤖 AI Complaint Analysis

The application uses AI to analyze submitted complaints and provide:

- Issue category
- Priority level
- Complaint summary
- Recommended department
- Intelligent issue analysis

### 📋 Smart Complaint Tracking

Students can track their complaints through different stages:

**Submitted → Reviewed → In Progress → Resolved**

This improves transparency and allows students to monitor the progress of their reported issues.

### 🗺️ Campus Issue Map

An interactive campus map allows users to view issue locations such as:

- Main Gate
- Academic Block
- Library
- Computer Lab
- Cafeteria
- Hostel
- Sports Ground
- Parking Area

### 🔎 Lost & Found

Students can report lost or found items with:

- Item details
- Image
- Location
- Description

AI-based matching can help identify possible matches between lost and found items.

### 💬 AI Campus Assistant

Students can interact with an AI assistant to get help with campus-related queries such as:

- How to report an issue
- How to track a complaint
- Information about campus services
- Pending complaint queries

### 📊 Admin Dashboard

Administrators can:

- View all complaints
- Filter issues
- Monitor priority complaints
- Update complaint status
- Analyze issue categories
- Monitor campus issue trends

### 📈 Analytics & Insights

The platform provides insights based on:

- Issue categories
- Complaint status
- Campus locations
- Priority levels
- Resolution trends
